# 표선고 IB 평가방문 통역 데스크 (Live Interpreter Note)

제주 표선고등학교(공립 IB 월드스쿨) 공식 **프로그램 평가 방문(Programme Evaluation Visit)** 통역 지원을 위해 설계된 정적 웹 애플리케이션입니다.

별도 백엔드 서버 없이 **노트북·태블릿 브라우저에서 즉시 동작**하며, 입력한 Google Gemini API 키는 사용자 브라우저(`localStorage` 또는 공용 PC용 `sessionStorage`)에만 안전하게 보관됩니다.

## 핵심 기능

1. **실시간 영 → 한 / 한 → 영 받아쓰기 및 직독 번역 (최신 발화 최상단 배치)**
   - 새로운 발화가 시작될 때마다 항상 **화면 맨 위**에 `최신 발화` 배지와 함께 표시되어 스크롤 없이 즉시 시선을 고정할 수 있습니다.
   - `영 → 한 듣기 (Alt+1)`: 방문 평가단(Visiting Team)의 영어 발화를 실시간으로 받아쓰고, 바로 아래에 한국어 번역을 실시간 스트리밍합니다.
   - `한 → 영 듣기 (Alt+2)`: 표선고 교원·학생·리더십팀의 한국어 발화를 실시간으로 받아쓰고, 바로 아래에 IB 공식 레지스터에 맞춘 영어 번역을 실시간 표시합니다.
2. **[중간 정리] 화자 대화 요약 · 실전 통역 제시문 · 자동 저장 및 PC `.txt` 입출력**
   - 상단 **`중간 정리 (Alt+S)`** 버튼을 누르면 해당 화자가 지금까지 말한 내용을 종합해 **1) 화자 대화 핵심 요약**과 **2) 바로 전달할 수 있는 반대 언어 통역 제시문**을 정리해 보여줍니다.
   - 생성된 내용은 브라우저 보관함에 **자동 저장**됨과 동시에 내 PC에 UTF-8 `.txt` 파일로 자동 다운로드되며, 우측 상단 **`기록 불러오기`** 서랍에서 자동 저장 목록을 다시 열거나 PC의 `.txt` 파일을 드래그·선택해 추후 언제든 불러올 수 있습니다.
3. **내 말로 통역하기 위한 AI 핵심 브리핑 & 반대 언어 단어장**
   - 개별 발화마다 **핵심 논지 구조(개조식 요약)**, **반대 언어 말하기 뼈대(Speaking Cue)**, **놓치면 안 되는 수치·고유명사 체크**, **원어 ↔ 반대 언어 핵심 어휘 카드**를 우측 패널에 즉시 정리합니다.
4. **표선고 · IB 월드스쿨 맞춤 용어집 기본 탑재 및 직접 추가**
   - `PSP`, `PDP`, `SSQ`, `IA`, `내부 채점 기준화 협의(Internal Standardization)`, `전문적 학습공동체(PLC)`, `동행관`, `제주특별자치도교육청` 등 50여 개의 핵심 용어가 기본 탑재되어 발화 즉시(0초) 매칭되며, 현장에서 필요한 맞춤 용어를 자유롭게 추가·상단 고정(Pin)할 수 있습니다.

## 단축키 안내

- `Space`: 실시간 마이크 듣기 시작 / 일시정지
- `Alt + 1`: `영 → 한 듣기` 모드로 즉시 전환
- `Alt + 2`: `한 → 영 듣기` 모드로 즉시 전환
- `Alt + S`: **`중간 정리`** 실행 (화자 대화 요약 + 통역 제시문 생성 + 자동저장 및 PC `.txt` 저장)
- `Enter`: 현재 발화 구간 완료 및 AI 핵심 요약 즉시 갱신

## 로컬 실행 및 배포 방법

```bash
npm install
npm run dev
```

### GitHub Pages 배포 (자동화 설정 완료)
이 저장소에는 `.github/workflows/deploy.yml` 워크플로우가 포함되어 있습니다.
GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 지정하면 `main` 브랜치 푸시 시 자동으로 웹 링크가 생성되어 현장의 노트북·태블릿에서 바로 접속할 수 있습니다.
